# src/data — 콘텐츠 데이터 폴더

이 폴더의 JSON 파일들은 **임시 더미 데이터**입니다. 실존 인물·논문·소식이 아닙니다.

## 목적

- 지금은 사이트를 개발하는 동안 화면에 채워 넣을 예시 데이터입니다.
- 나중에는 **Google Sheets(CSV 게시)** 와 **Notion API** 에서 빌드 시점에
  실제 콘텐츠를 가져와 이 자리를 대체할 예정입니다.
- 그때부터 콘텐츠 수정은 이 파일이 아니라 **Google Sheets / Notion 에서** 합니다.

## 파일별 스키마 (필드 이름은 실제 연동 시 조정될 수 있음)

### members.json — 구성원

| 필드 | 설명 |
| --- | --- |
| `id` | 영문 소문자 + 하이픈 식별자 |
| `name` | 이름 (국문) |
| `nameEn` | 이름 (영문) |
| `role` | 직책 (예: 지도교수, 박사과정, 석사과정) |
| `field` | 연구분야 |
| `email` | 이메일 |
| `joinedYear` | 합류 연도 (숫자) |

### publications.json — 논문

| 필드 | 설명 |
| --- | --- |
| `id` | 영문 소문자 + 하이픈 식별자 |
| `title` | 논문 제목 |
| `authors` | 저자 목록 (문자열 배열) |
| `venue` | 학회 / 저널 이름 |
| `year` | 발표 연도 (숫자) |
| `type` | 종류 (`journal`, `conference`, `workshop` 등) |
| `link` | 논문 링크 URL |

### news.json — 소식

| 필드 | 설명 |
| --- | --- |
| `id` | 영문 소문자 + 하이픈 식별자 |
| `date` | 날짜 (`YYYY-MM-DD`) |
| `title` | 소식 제목 |
| `summary` | 요약 내용 |

## 규칙

- 이 폴더의 데이터 파일에는 파일 줄 수 상한 규칙을 적용하지 않습니다.
- 데이터를 코드에서 읽을 때는 항상 `src/lib/content.ts` 를 통해서만 가져옵니다.
  (데이터 출처를 나중에 한 곳에서 바꾸기 위함)
