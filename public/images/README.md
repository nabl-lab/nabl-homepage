# public/images

사이트에서 쓰는 이미지 파일을 이 폴더에 둡니다. `public/` 아래 파일은
빌드 시 경로 그대로 복사됩니다. 예: `public/images/hero.jpg` → `/images/hero.jpg`

## hero.jpg — 홈 히어로 배경

- 홈 화면 상단 히어로의 배경 이미지 자리입니다. (연구실 사진 등)
- 파일명은 정확히 `hero.jpg` 로 넣으면 자동으로 적용됩니다.
- **파일이 없으면** 히어로는 크림슨 단색 배경으로 표시됩니다 (에러 없음).
- 권장: 가로로 긴 사진, 가로 1920px 이상, 용량 300KB 이하로 압축.
